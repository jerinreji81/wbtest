# Tools Feature

Owns Tools tab helper logic and subfeature controller boundaries.

## Current controllers

- `tools-controller.js` — Tools panel state, Key/Capo helper logic, pad selector state/status helpers.
- `bible-controller.js` — Bible version/book/chapter metadata, Bible state normalisation, chapter navigation, cache identifiers, and chapter payload normalisation.

## Still in legacy shell

- Tools DOM rendering
- Bible DOM rendering
- Bible local/Firebase fetch adapters
- Pad audio playback

No visual redesign is included in this phase.
